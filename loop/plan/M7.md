# M7 · 跨任务自进化 + 可回退（把"自进化"和"可回退"接成一个闭环）

## 〇、本阶段人话目标

现在有两样东西各自能用，但没连起来：
- **EvoUndo**：任务内能回滚（一次任务里的版本链）
- **experience.py**：跨任务能积累经验（append-only，带证据）

缺的是：**经验本身也要能回退，而且它被用得好不好要能被度量。**

做完之后要能回答三个问题：
1. 这条经验被用过几次？用过之后成功率多少？
2. 某条经验在新任务上失效了，系统会自己把它降权吗？
3. 把所有任务的版本链串起来，能不能看出"这个系统一共进化了几代"？

## 一、口径

- **经验的"版本"**：`learned`（学到）→ `confirmed`（被后续任务验证有效）→ `contradicted`（被证伪）
- **降权是自动的**：同一条经验被证伪 2 次，自动移出推荐池（但不删）
- **跨任务版本链**：每个研究任务是一条链，链之间用 `parent_run` 串（如果某个任务是"在上一轮基础上继续"）

## 二、开工前必做

1. `git status` 看工作区
2. 读：`experience.py`（现有经验库）、`evoundo.py`（版本链）、`research_loop.py` 的 `_learn` 和 `_adversarial_check`

## 三、具体实施步骤

1. **扩展 `experience.py`**：
   - 经验记录加 `used_count` / `success_count` / `contradicted_count`
   - 加 `record_usage(record_id, improved: bool)` —— 每次用某条经验后回写结果
   - 加 `active_pool()` —— 只返回没被降权的经验（`contradicted_count < 2`）
   - 加 `lineage()` —— 输出经验池的"进化账"：总条数、有效率、被否证数
2. **接进 `research_loop.py`**：
   - 用了哪些经验进 prompt（已经有 `experience_matched` 事件）
   - 结尾拿到结果后，对每条用过的经验调 `record_usage(improved=True/False)`
3. **加一个跨任务总账**：`tools/evolution_report.py`，扫所有 `artifacts/evoundo/*/versions.json`，输出：
   - 一共跑过几个任务、几代版本、几次回滚
   - 经验池的有效率
