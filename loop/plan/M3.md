# M3 · 自迭代证明（证明"它真的越用越好"，而不是口号）

## 〇、本阶段人话目标

comment4 要的是"agent 是否可以自我迭代并改进"。现在我们有经验记忆（`experience.py`），
但它只被证明过"能被检索到"，没被证明过"带来了改进"。

这一阶段要拿出**对照证据**：同一个任务跑多轮，看成本/速度有没有真的下降。

## 一、口径（这条最容易作弊，先定死）

- **对照组**：每次跑都清空经验库（或指向一个空库）
- **实验组**：用同一个经验库累积
- **同任务**：同一个 CSV、同一个 metric、同一个模型、同一个预算上限
- **允许的"N 轮"**：同一任务重复跑不是作弊——因为系统面对的是一个重复出现的任务类型，
  这正是"跨任务经验积累"要解决的事

**判据（任一条成立即算改进，但要说明是哪条）**：
1. 达同样分数所需实验数减少（`experiments_used` 下降）
2. 达同样分数所需 token 减少（`local_tokens` 下降）
3. 达同样分数所需时间减少（`elapsed_seconds` 下降）

**如果三条都不成立**——那是诚实的负面结果，照样写进报告，不许改口径凑。

## 二、开工前必做

1. 确认 M1 / M2 已完成（`progress.log`）。
2. 读 `experience.py`、`tools/run_five_roles.py`、`research_loop.py` 的 `_learn`。

## 三、具体实施步骤

1. **新建 `tools/run_selfiter.py`**：
   - 参数：`--task <csv> --rounds N --experience <path> --fresh-control`
   - 每轮跑一次完整研究闭环，记录：`round, best_score, experiments_used, local_tokens, elapsed_seconds, experience_count`
   - `--fresh-control` 时每轮清空经验库（用临时文件，不动真库）
   - 输出 `artifacts/selfiter/<任务名>_<时间>.json` + 一张对照表（文本即可）
2. **跑两组**：
   - 实验组：`--rounds 4`（同一个经验库累积）
   - 对照组：`--rounds 4 --fresh-control`
3. **写结论**：三条判据逐条给"成立 / 不成立 + 数字"。

## 四、真实测试与验收判据（不许改宽）

1. `tests/test_selfiter.py` 至少 3 条（用假 session，不跑真模型）：
   - 每轮记录字段齐全
   - 对照组的经验库每轮都是空的
   - 实验组的经验数单调不减
2. 全量测试 ≥ 上阶段基线 + 3
3. **真跑两组**，贴出真实对照表（不许编）

## 五、本阶段红线

- 不许让实验组"偷偷多给预算"
- 不许在对照组里也读经验库（那就不叫对照了）
- 三条判据都不成立时**不许**改口径，必须如实写"未观察到改进"
- 不许只跑 1 轮就说"改善了"
