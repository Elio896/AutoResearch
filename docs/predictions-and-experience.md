# 预测交付与历史方案复用

V10 增量保留来源、分类、低高成本工作站、最终审核、原报告导出及旧任务查看。

报告新增 research_outputs：对原问题的直接回答、验证记录的逐条预测和概率、真实类别、类别数量、字段置换重要性和限制说明。source_row 为原 CSV 数据记录的 1 起始序号，不是客户身份。仅用验证行，不读取保留测试集；独立新客户预测尚未提供。概率未经校准，字段重要性不代表因果或影响方向。重要性使用固定最多 300 条验证记录、2 次置换，属于探索证据。用户原始目标及这些证据交给最终审核。

历史最优方案从已审核通过的持久报告恢复，严格匹配数据 SHA256、目标列、seed、评价指标、正类、特征处理及剔除列。本轮先重训验证历史方案，分类工作站仍可尝试改进，程序拒绝退化结果。历史分数不是新的计算结果；同方案不重复训练，不把重复实验记为提升。首次或无匹配经验才使用逻辑回归基线。经验属于相同数据上的策略复用，不声称跨数据学习或模型权重学习。

预测 CSV 接口：/ml/runs/{run_id}/predictions。旧报告未包含预测时保持原状，不伪造补齐。
