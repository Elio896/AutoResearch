# 路演脚本 · 8 分钟版

> 用途：现场路演（8 分钟）；文末有 5 分钟压缩版删减表、12 个必问 Q&A、翻车预案。
> 所有数字都能在现场的 `runs/demo_readmission/` 里查到——**这是这套脚本唯一的底气**。

**道具**
- 一台跑得动的笔记本，预先跑好 `make_demo_run.py`（5 轮，7 秒）
- 终端窗口 1：`validate_trace.py`（现场演示 6 秒校验）
- 终端窗口 2：`trace.jsonl`（左右分屏，滚轮停在 r003）
- 备用：90 秒录屏（U 盘 + 本地各一份，**不依赖网络**）

**角色**
- 讲者 A（二德子）：主叙述 + 操作
- 讲者 B（肯肯/猫）：只负责被追问时接一句，以及最后 CTA

## 0:00–0:40 钩子：一个 96% 的模型，什么都没抓到

**画面**：一张表，两行数字，没有标题。

```
欺诈检测模型
accuracy 0.962 ✓
F1        0.241
召回      0.150   ← 100 个欺诈，抓到 15 个
```

**台词**

> 先看一个数：这个欺诈模型的准确率是 96.2%。
> 但如果你把 8000 笔交易全部判成"正常"，准确率是 96.0%。
> 也就是说，这个模型比"什么都不做"只多对了 0.2 个百分点。
>
> 这不是我们编的错例。这是每一支队伍都会踩的坑，也是大模型做研究时最常见的幻觉——
> **它给你一个漂亮数字，然后告诉你实验成功了。**

**动作**：停 2 秒。不要解释。

---

## 0:40–1:30 痛点：AI 做研究有两个死结

**画面**：两行字。

**台词**

> 大模型做科研有两个硬伤。
>
> 第一，**科学幻觉**。公式推错、量纲不守恒、数据编造。它错的时候语气和它对的时候一模一样。
>
> 第二，**自进化崩塌**。让 Agent 自己改自己，有两个死结：稀疏奖励——不报错就不进化；灾难性退化——一变异就越改越坏。
>
> 市面上的做法是"多调几轮 prompt"。我们的判断是：**这不是 prompt 问题，是缺少可验证的账本。**

---

## 1:30–2:20 主张：刚性校验 + 可回滚的版本链

**画面**：一句话居中。

> 每个结论都必须挂一串能复现的数字；每次改动都必须能退回上一版。

**台词**

> 所以 EvoResearch 只做两件事。
>
> 一，**刚性校验**。分数不是模型说的，是编译器、是 sklearn、是 5 折交叉验证跑出来的。模型没有"我觉得"的权限。
>
> 二，**可回滚的版本链**。每一次实验绑定一个快照：数据哈希、划分哈希、代码 commit、参数、结果。分数降了或者踩红线，自动退回历史最优点。
>
> 一句话：**我们不是让 AI 更会做研究，是让它做的研究可以被审计。**

---

## 2:20–3:00 架构：五个角色，一个 LLM

**画面**：五个方块 + 一条预算条。

```
Manager  ── 分预算、决定何时停
Analyst  ── pandas 查缺失/异常/不平衡
Scientist── 提假设（唯一必须调 LLM 的地方）
Experimenter ── sklearn 真训练，token = 0
Reviewer ── 算指标、开闸门、给回滚建议
```

**台词**

> 五个角色不等于五个大模型。能算的用 Python 算，只有"判断"才调 LLM。
> 所以训练那一层，token 消耗是 0——**这是架构决定的，不是优化出来的**。
> 每一轮花多少 token、多少秒、第几次实验，都记在同一本账上。

## 3:00–5:20 现场：五轮，两个"失败"

**画面**：切到终端，执行（或直接展示已跑好的）结果。

```
r000_baseline            F1=0.165  Δ +0.000  kept
r001_missing_indicator   F1=0.443  Δ +0.277  kept      ← 缺失本身是信号
r002_class_weight        F1=0.554  Δ +0.111  kept
r003_drop_missing_rows   F1=0.343  Δ -0.211  reverted  ← 被拦下
r004_threshold_sweep     F1=0.555  Δ +0.002  reverted  ← 没过 MDE，拒绝
```

**台词（讲到 r001 时放慢）**

> 数据是 2400 个病人，预测 30 天内会不会再入院。五列有缺失，最高的缺失 19%。
>
> 第一轮基线，中位数填补，F1 是 0.165。
>
> 第二轮，Scientist 提了一个假设：**这些缺失不是随机的**。越可能再入院的病人，医生越会给他查糖化血红蛋白。所以"这项检查没做"这件事本身，就是一个信号。
> 加五个缺失指示变量——不是填补，是**把"缺失"当成特征**——F1 从 0.165 到 0.443，5 折全部同向。
>
> 第三轮加类别权重，0.554。

**台词（讲到 r003，语速加快但要清楚）**

> 第四轮，我们故意让它试一个常见错解：把含缺失的行全删了，用"干净"数据训练。
> 结果 0.343。样本掉了一半，**丢掉的正是信号本身**。
> 闸门拦下了这一轮，自动回滚到第三轮。
>
> 第五轮，扫阈值，涨了 0.002。
> 这个数小于最小可检测效应 0.020，按我们自己的规则，**判定为噪声，不采纳，回滚**。

**动作**：停。看向评委。

## 5:20–6:00 全场最高点：为什么"拒绝"比"提升"更值钱

**画面**：只有一行。

> 一条全是"成功"的轨迹，是可疑的轨迹。

**台词**

> 现在回头看我刚才讲的五轮：涨了两次，**失败两次**。
>
> 但真正说明这套系统可靠的，不是 0.165 到 0.554，是后两次。
> 一个只会报告"我又提升了"的系统，你没法判断它是在学习还是在过拟合。
> 一个会告诉你"这一轮我试了，没用，我退回去了"的系统，你才敢让它继续跑。
>
> 这也是为什么我们把"轨迹里必须有一次回滚记录"写进了验收表——**没有失败记录的轨迹，不予通过。**

token 0 / 200,000 训练层不调 LLM
墙钟  6s / 15min

**台词**

# Q&A · 12 个必问题

**1. 这跟 AutoML 有什么区别？**
AutoML 搜的是超参空间，我们搜的是**假设空间**，而且每个假设必须能被证伪。AutoML 不会告诉你"我试过删行、更差、我退回了"。另外我们的产物是**可审计的轨迹**，不是一个模型文件。

**2. LLM 提的假设靠得住吗？**
不靠。所以假设不是结论，**假设只是待验证的猜测**，必须带 `falsifier`（什么结果算它错）。扛住 5 折、过了 MDE 才留下。LLM 在系统里唯一的特权是"提问"，不是"下结论"。

**3. 回滚是不是在掩盖失败？**
相反，回滚是**把失败变成资产**。失败轮照样进轨迹、照样占预算、照样记原因。评委看到 r003 掉 0.211 被拦下，比看到一条全是 +0.01 的直线更可信。

**4. 数据是合成的吧？**
是，`gen_data.py` 生成，固定种子，逐字节可复现。**但结论不是合成的**：三个数据集的标定、参考上限、泄漏线都是真跑出来的，脚本在仓库里，你可以换自己的 CSV 重跑。合成数据让我们能控制"病灶"——干净/缺失/不平衡各一份，才能测出系统在不同情况下的行为。

**5. 为什么不用 GPT-4 / Claude？**
成本 + 计量 + 可控。DeepSeek 的 usage 字段可以直接入账，token 能统计才能做预算控制。换模型只改一个路由，轨迹格式不变。

**6. 一晚上能跑多少个实验？**
预算上限 20 轮，实测单轮训练 0.02–1.3 秒。真正的瓶颈是 LLM 决策，不是训练。

**7. 你怎么证明"钱花得值"？**
看三条线：同预算下的 F1、同 F1 下的 token、以及失败轮占比。第三条最容易被忽略——**一个不会失败的搜索，通常也没有在搜索**。

**8. 如果评委现在给你一份新数据？**
`gen_data.py` 换成他的 CSV，`baseline.py` 重跑标定定及格线，然后跑。**及格线必须按新数据重标**，不能沿用——这条写进验收说明了。

**9. 五个 Agent 会不会互相甩锅？**
每个角色的输出都是结构化字段，写进同一份 record：Analyst 写 `input.profile`，Scientist 写 `hypothesis`，Reviewer 写 `validation`。**谁的字段有问题，脚本指到字段级**，不靠开会吵。

**10. 这套东西两个比赛怎么复用？**
核心九项证据一个字不改；差异全部放进 `ext` 命名空间。换比赛只加字段，不改 `required` 列表——这就是"可复用"的可验证含义。

**11. 你们的 F1 也不算高啊（0.55）。**
对，而且我们特意没把它做成 0.95。数据里埋了泄漏字段，做到 0.94 只要一行代码——但那是作弊。**0.55 是在"不许泄漏、不许挑测试集"的约束下的真数**，而且每一折都能复现。

**12. 最容易被问倒的是什么？**
"你的 MDE 怎么定的？"——答：1.5 × (5 折 std / √5)，写死在 `result.mde` 字段里，Δ 小于它就是噪声。这个规则**同样约束我们自己**，r004 就是被它否掉的。
