**先看一个数字。**

我们做了一个信用卡欺诈检测模型，准确率 **96.2%**。

听起来还行？把 8000 笔交易全部判成"正常"，准确率是 **96.0%**。

也就是说，这个模型比"什么都不做"，只多对了 0.2 个百分点。它的 F1 是 0.241，召回 0.15——**100 笔欺诈，它抓到 15 笔**。

这不是段子，是每个做不平衡分类的人都会踩的坑，也是大模型做科研时最常见的幻觉：它给你一个漂亮的数字，然后用同样自信的语气告诉你"实验成功了"。

---

### 一、大模型做科研的两个死结

我们把问题拆成两个。

**第一个是科学幻觉。** 公式推错、量纲不守恒、数据编造。问题不在于它会错——人都 会错——而在于**它错的时候和它对的时候，语气一模一样**。你没法从文本里判断哪句该信。

**第二个是自进化崩塌。** 现在很流行让 Agent 自己改自己：改 prompt、改代码、改策略。但这条路有两个死结：

- **稀疏奖励**：不报错就不进化。跑通了就认为没问题，于是永远停在"能跑"的水平。
- **灾难性退化**：一变异就越改越坏，而且它自己发现不了。

我们试过一个很朴素的方案：把上一轮的报错塞回 prompt 让它重生成。错误数从 1 降到 0，有效。但下一个问题是——**怎么证明新的比旧的好，而不是换了个随机种子？**

这个问题不解决，所谓"自进化"就是一场自说自话。

---

### 二、我们的答案是：刚性校验 + 可回滚的版本链

两句话：

> 每个结论都必须挂一串能复现的数字。
> 每次改动都必须能退回上一版。

具体到工程上，是五个角色的分工——但**五个角色不等于五个大模型**：

| 角色 | 干什么 | 谁在算 |
|---|---|---|
| Manager | 分预算、决定何时停 | Python 规则 |
| Analyst | 查缺失、异常、类别不平衡 | pandas |
| Scientist | 提假设、选实验方案 | **LLM（唯一必须调的地方）** |
| Experimenter | 真训练模型 | scikit-learn，**token = 0** |
| Reviewer | 算指标、开闸门、给回滚建议 | Python 指标 + LLM 解读 |

能算的用 Python 算，只有需要"判断"的地方才调 LLM。所以**训练那一层，token 消耗是 0**——这是架构决定的，不是优化出来的。

### 三、一次真实的五轮实验

我们用一份 2400 行的再入院数据（预测 30 天内是否再入院，正例 28%，五列有缺失）跑了五轮。

```
r000_baseline            F1=0.165   kept
r001_missing_indicator   F1=0.443   Δ+0.277   kept
r002_class_weight        F1=0.554   Δ+0.111   kept
r003_drop_missing_rows   F1=0.343   Δ−0.211   reverted
r004_threshold_sweep     F1=0.555   Δ+0.002   reverted
```

每一行的数字都是当场跑出来的，5 折交叉验证，固定种子，脚本在仓库里。

**第 2 轮是这次实验里最有意思的一步。**

数据里糖化血红蛋白缺失 19%。第一反应是填补——中位数、均值、KNN，随便哪种。但 Scientist 提了个不同的假设：

> 这些缺失不是随机的。越可能再入院的病人，医生越会给他查这项指标。所以"这项检查没做"这件事本身，就是一个信号。

于是我们**不填补，而是把"缺失"变成特征**：加五个 `isna` 指示变量。F1 从 0.165 到 0.443，5 折全部同向。

这不是调参调出来的，是**对数据生成机制的一次判断**，而且这个判断可以被证伪——如果加了指示变量没提升，假设就不成立。

**第 4 轮更有意思：我们故意试了一个常见错解。**

"缺失值污染模型？那把含缺失的行删了不就行了。"

删完只剩 48% 的样本，F1 掉到 0.343。**删掉的正是信号本身。** 闸门拦下这一轮，自动回滚到第 3 轮。

**第 5 轮：扫阈值，涨了 0.002。**

0.002 小于我们设定的最小可检测效应 0.020，按规则判定为噪声，**不采纳，回滚**。

---

### 四、真正说明系统可靠的，是后两次"失败"

如果只看 F1，这个故事的高潮是 0.165 → 0.554。

但我觉得真正值钱的是后面两轮：一次掉 0.211 被拦住，一次涨 0.002 被拒绝。

原因很简单：

> 一条全是"成功"的轨迹，是可疑的轨迹。

一个只会报告"我又提升了"的系统，你没法判断它是在学习，还是在过拟合验证集。一个会告诉你"这一轮我试了，没用，我退回去了"的系统，你才敢让它继续跑。

所以我们把这条写进了验收规则：**轨迹里没有一次回滚记录，不予通过。** 反过来，如果一条轨迹从头到尾全是 kept，我们的第一反应是——闸门没起作用，或者假设太保守。

---

### 五、怎么让"证据"这个东西可执行

光说"要留证据"没用。我们把它拆成了九项，缺一项，这一轮就不算数：

| # | 证据 | 没有它会被怎么质疑 |
|---|---|---|
| 1 | 身份与血缘（轮次、父轮、哈希） | 这轮是哪轮？凭什么说是它导致的变化？ |
| 2 | 输入快照（数据 sha256、划分哈希、种子） | 你换数据了吧？ |
| 3 | 假设与可证伪预测 | 先跑再看结果编故事 |
| 4 | 干预清单（字段级 diff） | 你到底改了什么？ |
| 5 | 执行凭证（命令、commit、环境、退出码） | 这分是手填的吧？ |
| 6 | 结果与不确定性（每折、std、CI、MDE） | 一次运气好也算提升？ |
| 7 | 闸门与回滚 | 坏了也没人拦，越改越差 |
| 8 | 预算台账（双账对账） | 预算守住了吗？谁记的账？ |
| 9 | 结论与下一步 | 所以呢？ |

再加三条硬约束：

- **链式哈希**：每轮记录算 sha256，`prev_hash` 指向上轮。改任何一轮，后面全对不上。
- **复现三元组**：`split_hash + split_seed + env_hash`，缺一个别人就重建不出你的实验。
- **预算双账**：自己记的账 vs 网关调用日志，误差超 1% 轨迹作废。

写成了 JSON Schema + 一个零依赖的校验脚本。你可以现在改一个数字再跑一次：

```
FAIL  1  CHAIN_HASH   记录的 self hash 与内容不符（被改过）
FAIL  1  DELTA_MATH   delta=0.2771 与 value-baseline=0.5466 不符
FAIL  1  CI_COVER     value 0.712 不在 ci95 [0.4053, 0.4797] 内
```

四个独立检查同时报警。**这才是"可审计"的意思：不是我相信你，是我不需要相信你。**

### 六、必须承认的三件事

知乎上写技术文，最容易被抓住的是"只讲好的"。所以：

**1. 数据是合成的。** `gen_data.py` 生成，固定种子，逐字节可复现。这样做是为了控制"病灶"——干净/缺失/不平衡各一份，才能测出系统在不同情况下的行为。**但结论不是合成的**：参考上限、及格线、泄漏线都是真跑出来的，换你的 CSV 重跑就行。

**2. F1 只有 0.55。** 对，而且我们特意没做成 0.95。数据里埋了一个事后字段（`chargeback_filed`），放进去 F1 立刻 0.943——一行代码的事。但那是泄漏，不是能力。0.55 是在"不许泄漏、不许挑测试集"约束下的真数。

**3. 这次 demo 没接 LLM。** 五轮里的假设文本是脚本预置的，token 记账因此是 0。数字是真的，但"Agent 自己提出假设"这一步，我们在真实链路里跑，长度和这里不一样。不吹这个。

---

### 七、所以这东西到底有什么用

短期看，它是一个能自己跑实验、自己回滚的科研助理。

但我觉得更有价值的可能是那份**轨迹规范**。它跟具体模型无关：你换 GPT 还是 DeepSeek，换 sklearn 还是 XGBoost，九项证据一个字都不用改。两个比赛、两套评审标准，也能复用同一套结构——差异全部塞进 `ext` 字段，核心区不动。

如果这条路走通，"AI 做科研"的验收标准可能会变：从"看它报告了什么"，变成"看它的痕迹能不能被别人重跑一遍"。

**让 AI 做研究不难。让它的研究能被别人重做一遍，才难。**

## 版本 B · 短答（约 400 字）

> 适合挂在「AI 做科研靠谱吗」「大模型能不能替代研究员」这类问题下。

**不太靠谱，但不是因为它不够聪明，是因为它不承认自己错。**

我们做过一个实验：让 Agent 自己跑 5 轮机器学习实验。第一轮基线 F1 0.165，第二轮它发现"数据里的缺失不是随机的、缺失本身就是信号"，加缺失指示变量，0.443；第三轮加类别权重，0.554。

如果故事到这里结束，就是一篇标准的"AI 超越人类"爽文。

但第四轮，它试了"把含缺失的行删掉"，F1 掉到 0.343；第五轮扫阈值，涨了 0.002。我们的规则是：涨幅小于最小可检测效应就算噪声。所以后两轮都被回滚了。

**关键不是它涨了多少，是它敢说自己哪一轮白干了。**

大模型做科研最大的问题不是幻觉本身，是幻觉没有成本。你没法验证，它也不用负责。所以我们的做法很土：每轮强制留九项证据——数据哈希、划分种子、假设的可证伪条件、字段级 diff、执行命令、每折指标、闸门记录、预算双账、结论。链式哈希，改一个数字整条链就断。

一句话：**不是让它更会做研究，是让它做的研究可以被审计。**
