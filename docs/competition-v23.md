# V23：比赛收尾与复现

当前产品是面向**表格分类预测与描述性关联分析**的预算感知 Research Agent，不宣称覆盖所有科研领域。默认入口为项目根目录 `Start-Local-Research.cmd`，地址 `http://127.0.0.1:8018/`。保留现有机器人和页面设计。

## 研究闭环

来源站理解自然语言并检索本地真实数据目录，或读取用户 CSV；分类站判断任务并派发；低成本站提出有假设和证伪条件的实验，失败或路由不确定时升级高级站；本地 sklearn/统计工具实际执行；验证器比较验证集成绩、拒绝退步并保留当前最佳；最后由审核大模型根据真实证据直接回答原问题。

网页新研究默认最多 **3 轮候选实验**，连续 **2 次无改进**停止。API 未传参数时保留旧版单轮行为。每轮将前轮实验、得分与未改进原因传给下一轮，不是把同一个问题独立重跑。调用、Token、时间、训练次数共享预算，并预留最终审核预算。达到上限不保证每轮都有新训练；重复配置、预算不足或已完成的关联分析会提前停止。

“哪些因素相关”和“预测哪些记录”分开交付。两类客户比较实际计算组内均值、中位数及类别比例。观察数据不能识别因果时明确说明，同时完成可支持的关联分析。不能用电信数据回答失业问题。

## 学习与可进化的准确口径

- 单次研究：根据真实实验反馈修改下一轮方案，验证后保留更优结果，退步回退。
- 跨次研究：只在数据哈希、目标、特征审查和评价协议相匹配时读取历史方案与经验；历史方案仍需重新训练验证。
- 这属于**系统层的经验适应**。没有微调大模型权重，也没有自动发布新的系统策略版本。`research_iteration_enabled` 与 `auto_evolution_enabled` 表达不同能力；后者继续为 false。
- 验证集用于方案选择，因此其提升不能作为独立测试集泛化提升的证据。

## 可复现命令

在项目根目录，用已经配置好依赖的 Python 执行：

```powershell
python -m unittest discover -s tests
python tools/bootstrap_catalog.py
python tools/bootstrap_catalog.py --churn
python tools/replay_ml_run.py artifacts/ml/<run_id> --output replay.json
```

`bootstrap_catalog.py` 使用现有 sklearn 真实数据；`--churn` 只在缺少客户流失数据时从固定 OpenML 40701 下载。网络失败会报错，不生成替代数据。复现工具校验数据 SHA256 并重新训练所有记录的配置，零 LLM 调用，不访问最终测试集；不承诺重放随机云端模型响应。

真实验收工具：

```powershell
python tools/finalize_competition.py --phase all --output artifacts/unique-evaluation-folder --cost-limit 0.20
```

先启动网站并在设置中保存有效模型配置。脚本不会索取、打印或复制密钥。每轮结果先落盘；源代码版本变化时停止，不混合不同版本。费用上限只在任务之间检查已知的官方价核算额，不等同于供应商账单扣费上限；未知用量必须保留为空。

## 统一验收协议

1. 三轮真实研究冒烟验证：记录每轮假设、配置、训练得分、保留/回退、预测文件。
2. 原 30 道问题：显式关联上轮任务，检查追问、格式、目标变更、领域不匹配、因果局限与下载。程序化结构检查不是答案语义正确率。
3. 多智能体与高成本单模型：4 个数据集、客户流失 3 个种子，共 6 对；同数据、划分、轮数、训练算法和预算，无历史经验。记录成功状态、宏 F1、少数类 F1、PR-AUC、混淆矩阵、费用、Token、模型耗时、训练耗时、总耗时。数据获取为两组共有步骤，不纳入这项对比。
4. 经验消融：3 个种子；各自先积累同一份历史，再复制到两个隔离目录，一组禁止读历史，一组允许读历史。获取历史的成本作为双方共有前置成本单独记录。只证明本数据/本协议的适应效果。

真实评测结果以对应 `artifacts/contest-*` 的冻结协议和原始 JSON 为准。失败与未知费用不记为零，不从比较记录中消失。最终结论还需人工核对是否回答了原问题。
