# 实验经验闭环

V11 在历史最佳方案复用和预测交付基础上增量加入程序实测总结，不增加大模型调用。

每次真实训练记录基线、提升或无提升的配置、验证分数、比较分数及来源任务。执行失败记录错误类型，不能把调用失败归因为模型能力差。即使任务后续审核失败，已经测得的实验事实也可保留。

经验以 SQLite 持久保存，作用域由数据内容 SHA256、目标、seed、评价指标、正类、特征审核和剔除列共同确定。工作站提示包含最近经验。只有完全相同的有效配置已实测无提升且其旧分数不高于当前最佳分数，才跳过原样重复；不禁止模型家族，不阻止新参数，不影响其他目标或数据。

页面增加本轮经验与教训，包含历史适用范围。总结来自程序对实验的归纳，不是大模型权重训练，也不声称跨领域进化。没有有效实验或数据未取得时，不生成虚假的效果教训。旧报告仍保留，V11 之后的新任务开始积累这些记录。

验证：21 项链路/回归测试通过，覆盖经验持久化、作用域隔离、不同参数允许继续试验，以及提示引用和重复无效实验跳过。新增功能尚未完成真实云端端到端复验。
