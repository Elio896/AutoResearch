# V22 部署复核与功能修复

## 修复

- 启动器与后台共享 `app_version.py`，检查实际版本及 `restart_required`。
- 后台源码指纹覆盖数据源、目录、关联分析、交付与经验模块。静态资源使用独立指纹，在线样式变化不再阻止提交。
- 区分“有明确父任务时默认接续”与“无父任务时识别追问”，首次提出缺数据的新问题不再被误诊成追问。
- 上传 CSV 的领域名称与目录匹配时，检查实际字段兼容性，避免解释已有结果却重新搜索。
- 关联分析追问保留 `partial_completed`。缺研究产物的回答不能把研究升级为 `approved`。
- “不要重新训练”“无需重训”等否定指令不会触发新实验，独立的正向执行要求仍正常识别。
- 账户观测、报告与费用信息写入后才发布结束状态，余额观测失败保留未知实扣并不破坏研究结果。
- 新任务清除旧工作站动作及旧用量显示。预测表展示预测类别的未校准分数，不以百分比暗示真实流失概率。
- 审核提示和校准解释明确：预测类别分数不等于固定的正类风险；零余额差也不等于零费用。
