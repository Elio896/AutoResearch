## 费用：实际观测与估算的边界

官方单价乘实际 Token 仍是估算，不是账户实扣。本轮没有把估算改名为实际费用。

已接入 LightModelClient 的官方 DeepSeek `GET https://api.deepseek.com/user/balance`，只向已配置的官方域名发送现有凭据，拒绝重定向，不向猜测的中转/第三方账单地址发密钥。自定义端点与 Jev 缺少已核实的账单适配，返回未知。

研究开始/结束各采一次余额；同一供应商密钥即使跨角色、模型或 base URL 路径，也只采一次。单次快照共享 2.5 秒读取窗口，最多 4 个账户；失败不覆盖研究结果或把未知金额记零。使用 Decimal 保留原币种，不强行折算 CNY/USD。

报告及导出新增 account_billing，包含带时间戳的前后余额与差额；失败任务的 partial.json 也尽量保存。本轮精确实扣 task_actual_charge 保留 null，因为账户窗口内可能有 DeepSeek 桌面等并发消费、充值和赠额变化。充值形成负差额也如实保留，不包装成省钱。

主卡显示本轮实扣待对账；读到余额时另显示“实际账户窗口变化”，明确不能归因于该任务。参考单价估算继续保留在高级详情供核查，未用账户差额计算模型级实扣、费用节省或加速比。

来源：DeepSeek 官方余额接口 https://api-docs.deepseek.com/api/get-user-balance/ （2026-11-14 核对，返回 currency/total_balance/granted_balance/topped_up_balance）；对话接口 usage 是用量字段，不等于逐请求账单。
