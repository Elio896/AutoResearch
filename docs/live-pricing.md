# 官方价格自动更新

V17 自动读取 DeepSeek 官方价格页和 TypeSafe 官方帮助页，页面打开时检查、每5分钟检查一次，另有立即刷新按钮。研究与对比调用也会在价格过期时启动后台刷新。抓取只访问固定 HTTPS 官方来源，不用模型、不携带 API Key、限时限量且不跟随未知跳转。

解析支持目前两款 DeepSeek 模型的美元/百万Token缓存命中、未命中、输出和高峰倍率，以及 Jev 输入单价/免费输出。验证型号列顺序、行含义、计价单位和时段结构；官网结构变化时拒绝猜测新价格，显示刷新失败并保留上次成功值。缓存存放后端 official-prices.json，重启可恢复。首次未在线核验的内置参考价明确标注，不称实时价。

页面显示每个供应商最近获取时间、当前单价、来源、更新中/已更新/过期状态；刷新在后台运行，不阻塞页面和研究操作。高峰节假日不确定与接口用量缺失仍显示范围或未知。更新的是官方公开单价，不是供应商账单实扣。

每次模型请求把当时采用的价格快照固定到调用记录中。后续刷新不会重算历史任务费用，对比报告也包含各次快照。不同调用可能采用不同时间的单价，应以各自记录为准。

验证包括真实官网抓取解析并缓存、断网保留旧价、拒绝单位变化、请求快照不随刷新变化、GET/POST价格接口调度刷新。真实抓取2026-11-14T12:21Z成功读取两个供应商；这些时间在北京时间为20:21左右。
