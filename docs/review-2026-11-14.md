## 一、唯一判据（这条不过，其他都白改）

**能展示的是它的输出件，不是它的脑子。**

| 可以展示（并标明来源） | 不可以展示 / 不可以声称 |
|---|---|
| 分析依据：它看到的数据画像、哪些活接得住 | 「思维链」「它心里在想什么」 |
| 执行计划：要跑哪些基础操作与分类 | 把它没说过的话算在它名下 |
| 结果复核：它对分数的意见 | 把程序规则生成的文字冒充成模型输出 |

分工固定：**基础操作与分类 → 千问；研究假设与复杂诊断 → DeepSeek；策略选择（要不要花钱、要不要回滚、停不停）→ Jev。**

实现上的对应关系：`thought.attribution === 'model'` 才允许署名 Tongyi Qianwen；
`'program'` 必须显示成「程序规则 · 非模型输出」。任何一条都不许两边模糊。

## 三、请重点评审这几处

1. **`_leak_candidates()` 的误报面**：AUC 高 ≠ 事后字段，真实业务里「强特征」也会到 0.95。阈值 0.90 是拍的，是否该改成「相对第二名的差距」或「去掉该列后分数跌幅」？
2. **漏检**：现在只扫数值列。类别型的事后字段（比如 `status='closed'`）完全扫不到，要不要补 target 编码后的 AUC 或分组频次检验？
3. **`_research_hypotheses()` 的状态**：`status` 恒为 `not_called`。将来 `use_cloud=True` 真调时，这里必须改成 `called`/`failed`，不能沿用默认值——现在是靠「没有代码路径改它」来保证，是否该显式断言？
4. **`format_ok` 的启发式**：模型正常回答里如果带引号或括号会不会误判？反过来，它答一段格式正确但内容臆造的句子，`format_ok=true`，界面上就不会有任何提示——**格式正确 ≠ 内容可信**，这一层要不要在文案里补一句？
5. **XSS 面**：`escapeHtml` 先转义、`richText` 再把 `**` 换标签，替换进去的是我方固定标签；`<pre>` 内只放转义结果。请确认没有绕过路径。
6. **页面默认不勾「调本地千问」**：`use_local_model: $('opt-local').checked`，默认 false，所以默认永远走规则分支。这是产品选择（演示不想依赖 Ollama），还是漏了默认值？
7. **`research` 没有落盘**：`/demo/execute` 的返回里没有回传 `research`，页面刷新就丢。要不要存进 session 并在结果页也展示一次？

## 五、研究假设的完整清单：现在覆盖了什么、还差什么

当前 `_research_hypotheses()` 只出五类（都由确定性信号触发，不编）：

| 触发信号 | 出什么问题 | 状态 |
|---|---|---|
| 单特征 AUC ≥ 0.90 | 泄漏排查：这列是不是事后字段 | ✅ 已覆盖（仅数值列） |
| 列名 `*_id` | 特征取舍：ID 列丢不丢 | ✅ 已覆盖 |
| 缺失率 > 1% | 缺失机制：MCAR / MAR / MNAR，要不要 isna 指示 | ✅ 已覆盖 |
| 类别不平衡 | 指标口径：macro 还是少数类 F1，阈值要不要扫 | ✅ 已覆盖 |
| 训练行数 < 1000 | 样本量：提升是不是噪声 | ✅ 已覆盖 |

还没覆盖、但我认为属于同一类「研究假设」（建议下一步补）：

1. **生成机制假设**：目标到底是线性可分的还是有交互项/阈值效应——决定线性模型够不够。
2. **共线/冗余**：`total_charges ≈ tenure × monthly` 这种强相关对，该拆还是该删，删了掉多少分。
3. **重复实体 / 分组切分**：同一病人多次入院、同一客户多条记录——随机切分会把同一个人同时放进 train 和 val，分数虚高。
4. **分布漂移**：train / val / test 的均值、缺失率、类别比例是否一致；按时间切分时尤其要看。
5. **提升是否真提升**：多 seed + 配对比较 + 置信区间，而不是单次切分的差值。
6. **理论上限**：这类数据结构能到的上限是多少，用来判「越调越高」的假进步。
7. **类别型事后字段**：非数值的泄漏列怎么扫。

注意边界：**「要不要继续跑、要不要花钱、要不要回滚」不是研究假设，是策略选择，归 Jev**，不要塞进 `① b`。
上面 7 条都属于「诊断和假设」，归 DeepSeek。
