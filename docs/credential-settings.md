# 一次配置、持续使用

V13 设置使用 Windows 当前用户 DPAPI 加密保存密钥到后端数据目录 credentials.dpapi。文件不含明文密钥，不写入浏览器 localStorage，不通过状态接口返回密钥。后台启动自动读取，浏览器重新打开、页面重置和后台重建都不需要重新输入；仅设置提交的非空字段会替换对应密钥，留空保留另一项。环境变量仍可作为尚未保存配置时的来源。

升级到 V13 后第一次需要在设置中保存一次；此前版本仅存内存，无法自动恢复已经丢失的配置。旧后台不返回 persisted:true 时，前端不会声称已加密保存。保存后连接验证仍有少量模型调用费用，打开网页或读取设置状态不调用模型。

加密配置绑定当前 Windows 用户与电脑，不等于跨设备账号同步；换电脑或 Windows 账号需要重新配置。DPAPI 是操作系统静态加密保护，不能阻止同一账户下的恶意进程。没有明文降级。加密或写入失败时保留原配置。

已验证真实 Windows DPAPI 加解密、重建 FastAPI 应用后恢复、只修改一个供应商密钥、状态接口不回传密钥、保存失败保留原值、跨域写入拒绝和输入错误不回显敏感值。共26项测试通过。测试使用占位密钥，不调用真实供应商。
