边界：只有一组小型真实数据与两组合成数据；同一数据集的三次切分相互重叠，不是独立样本，也不构成显著性检验。耗时包含模型请求及共享机器影响，不等于纯模型速度。每组测试集已经使用，不应再用这些成绩指导调参后宣称为全新测试。

后续可将固定基线作为显式预算内起点：三次额度先完成固定三方案，剩余额度才交给Agent。它是工程保底策略，不能冒充Agent优于固定搜索，也不保证测试集成绩单调提高。原冻结评估保持不变，后续策略需另标版本。
