# EvoResearch 本地研究策略对照实验

日期：2026-11-13。结论：当前本地 Agent 未超过固定搜索，尚无证据支持效果或成本优势。

## 协议

t2：少数类 F1，正类标签 1；t3：宏平均 F1。种子 42、43、44，每组采用完全相同的分层 60/20/20 切分，并校验切分指纹。每组上限为 3 次训练、2 次本地模型调用、60 秒。时间为停止启动新工作的软上限，不是强制取消。固定搜索无需模型调用。所有组保留测试集，全程未执行 finalize。

固定方案在运行前声明为：默认逻辑回归、balanced 随机森林 100 棵树、balanced 逻辑回归 C=0.1。Agent 使用现有控制器：默认逻辑回归起步，再根据验证反馈生成候选。没有按实验结果修改候选、阈值或数据。

## 观察与边界

18 组真实训练完成，24 次本地模型请求，0 次付费 API 请求，0 次测试集评测。固定搜索在 t2 的三个种子上均更好；t3 一个种子持平，其余固定搜索更好。两个 Agent 的最佳结果均停留在初始逻辑回归基线。

0.5B 每组先提交 C=0.001 的逻辑回归，再触发无效/重复方案拒绝；3B 全部可执行候选仍是逻辑回归。拒绝日志将格式错误和重复合并，不能据此断言每次拒绝的具体类别。3B 端点耗时更短，但它是 Ollama 量化服务，0.5B 是另一套 transformers 服务；不能把差异直接归因于参数规模。

本轮只覆盖两个数据集、三个种子；属于探索性结果，不能作为总体统计优势或最终泛化成绩。每组预算上限相同，实际用量不同。顺序轮换以减轻启动偏差，但未隔离 GPU 竞争、缓存、模型装载等因素；时间不是纯推理速度。与原五折 CV 基准口径不同。

t1 未纳入：其哨兵缺失值和单位修复尚需独立设计；已存在的目标泄漏守卫不等于完成数据清洗。没有私下读取云端密钥，Jev/DeepSeek 实测对照尚未完成。

## 下一次迭代建议

先给规划器加入仅来自训练集的数据概况、类别占比，以及验证集每类反馈；再研究如何在有限预算中保证候选多样性。固定搜索应长期作为对照和安全下限。后续策略修改必须单列新版本，保留本次原始结果，并用新增数据集验证，不能把反复看过的验证集当作未知测试集。

## 复现

在项目根目录运行（输出目录必须不存在）：

```powershell
.\.venv\Scripts\python.exe tools\compare_local_policies.py --output artifacts\comparison_new_run
```

需两个本地端点可用：11435 的 Qwen2.5-0.5B-Instruct:latest，11434 的 qwen2.5:3b-instruct-q4_K_M。该脚本不下载模型、不调用云端、不改变网页默认模型。输出包含依赖版本、数据与切分 SHA256、每次参数与事件、Token 报告、汇总。它是独立研究策略比较，未覆盖网页交互验收。
