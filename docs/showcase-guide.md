# 完整项目演示

在项目目录中，使用已有环境启动：

```powershell
& "C:\workspace\EvoResearch\.venv\Scripts\python.exe" -m uvicorn api:create_app --factory --host 127.0.0.1 --port 8010
```

浏览器打开 `http://127.0.0.1:8010/showcase`，终端保持运行。

## 演示顺序

1. 点击“运行纠错前实验”：基线加两份相同随机森林提案，真实训练 3 次，重复 1 次。
2. 保存预填的用户纠错：不要重复运行相同的实验。记忆写入本次演示独立 SQLite 文件。
3. 点击“运行下一会话”：重新创建研究会话与记忆对象，训练 2 次，重复 0 次，拦截 1 次；验证宏 F1 与第一步一致。
4. 点击“撤销纠错并做负对照”：撤销规则再训练 3 次，重复恢复为 1 次。用于验证行为变化确实与规则相关。
5. 点击“执行策略回滚”：在已验收策略记录的独立副本中实际恢复上一版本，保留原记录并追加回滚事件。
6. 下载本次证据，或展开研究事件，检查画像、方案、真实训练、评审、拦截与回滚记录。

四项设计贡献在页面下方对应说明：纠错可执行化、带作用域的长期记忆、实验与策略双闭环、预算伴随证据。这些是项目设计贡献，不作全球首创声明。

## 已验证与边界

`tests/test_showcase.py` 两项 API 集成测试通过：包含顺序约束、含糊反馈 pending、真实训练 3→2→3、重复 1→0→1、质量保持、独立策略副本回滚、证据下载和不污染正式反馈库。日志 `artifacts/showcase-acceptance.txt`。JS 语法检查通过。

此页不调用任何外部模型，不需要 API Key。提案为明确标注的脚本回放，分类器和指标真实执行；它验证执行约束及版本机制，不证明真实 LLM 自主学习。测试集未使用，未知自然语言错误不在保证范围内。浏览器视觉与实机交互本轮未验收。
