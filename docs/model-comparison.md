# 开发者对比实验

V14 开发者面板增加多智能体协作与高成本单模型对照。高成本模式全部生成与审核使用配置的 high 模型，不调用 Jev/low。它使用相同的训练工具和审核输出协议，不是无工具聊天基线。两边审核模型均为 high，输出预算匹配。

控制条件：固定同一 CSV/目标、SHA256、seed、60/20/20 划分、初始算法、可选算法/预处理、每组训练/调用/Token/时间限额。比较从固定数据进入研究开始，排除共用检索步骤；历史经验和最佳策略读取/写入均关闭，避免记忆优势混入模型路由对比。高成本模式不需要模型选择器，所以调用次数可自然不同。组顺序按 seed 预先随机化，避免永远同一方先跑，但仍有网络和缓存影响。

指标：真实输入/输出 Token、未对账调用、调用/训练次数、墙钟时间、模型请求时间、训练时间、验证宏 F1、少数类 F1、少数类 AP、混淆矩阵、审核状态、最终答案及结构交付检查。结构交付检查不是答案正确性评价。少数类由训练集频数确定，不靠验证集反推。对比不访问最终测试集。

可运行1或3对种子实验，展示每组指标、均值/标准差和配对差值（协作减高成本）。未对账Token不计算节省，失败结果保留，不记成零消耗；费用没有供应商对账时显示未知。少量种子不作统计优越性结论，不保证协作更省、更快或更好。

入口：POST /ml/comparisons，GET /ml/comparisons/{id}，GET /ml/comparisons/{id}/export。独立存储在 artifacts/ml/comparisons/{id}，不污染正式研究经验。每组预算独立，3对运行6组，须承担两边实际API费用。支持本地目录或已上传CSV。可通过 ?comparison={id} 恢复展示。
